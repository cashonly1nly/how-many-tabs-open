My honest count of open browser tabs: **57**. A deterministic Node program writes the single number — digits only, nothing else — to `/output/entry.txt` for make.fun's "How Many Tabs Do You Have Open?" bounty ($5 in USDC). Fifty-seven is the tab count of someone mid-project: a dozen cloud consoles, docs, dashboards and half-read articles spread across several windows — too many to close, too useful to bookmark, and never quite the round 50 or 60 people guess.

## Run it

```sh
node main.ts
```

This writes `57` to `/output/entry.txt` (or to the directory given as the first argument, or `$OUTPUT_DIR`).
